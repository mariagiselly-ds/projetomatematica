# projetomatematica
-
Este trabalho apresenta um site educativo desenvolvido para auxiliar na revisão de conteúdos de Geometria Analítica. A página aborda conceitos importantes como plano cartesiano, distância entre dois pontos, ponto médio, equação da reta, coeficiente angular e circunferência, reunindo explicações e fórmulas de forma simples e organizada.
